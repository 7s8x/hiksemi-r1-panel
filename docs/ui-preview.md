# 本地模拟预览

`ui_preview.py` 提供一个**不需要 R1 硬件**的页面预览，用于在开发机上调整布局和配色。

## 运行

在项目根目录执行：

```sh
.venv/bin/python ui_preview.py
```

然后打开 <http://127.0.0.1:8766/>。

## 它是什么

- 服务**只绑定本机回环地址**，不监听局域网，不连接 R1
- 页面来自真实的 `r1_web.html`，所以调整 HTML 后刷新浏览器即可看到效果
- 状态、曲线、风扇、RGB 操作只存在预览进程内存里，退出即丢弃
- 修改 `ui_preview.py` 本身后需要重启预览进程

## 它不是什么

- **页面数据全是假的**：磁盘序列号是 `DEMO-...`，运行时长、CPU 占用、温度都是编造的
- **没有真实登录和改密**，不要把它当作生产后端
- **不读 framebuffer**，不反映实体屏当前画面
- 不要把它改成监听 `0.0.0.0`，也不要部署到 PVE 上

预览通过而不是验收通过。布局是否真的正常，只有实体屏现场看过才算。

## 图标对比页

<http://127.0.0.1:8766/logo-options/> 提供 favicon 候选对比，可在 96 / 32 / 16 px 与模拟标签页下比较。候选源文件在 `logo-options/` 目录。

正式使用的图标是 `r1_web_favicon.svg`。`logo-options/` 下的其余稿件仅作设计参考保留，不是官方商标文件。
